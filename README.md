# 📊 Bank Loan Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Bank Loan Analytics Dashboard** developed using **Microsoft Power BI**. The dashboard analyzes loan application data to provide meaningful insights into loan performance, customer behavior, repayment patterns, and portfolio quality.

The objective of this project is to transform raw loan data into an interactive business intelligence dashboard that helps users understand key performance indicators and identify important trends and patterns.

---

## 🎯 Project Objectives

- Analyze overall loan application performance
- Track funded and received loan amounts
- Compare Good Loans and Bad Loans
- Analyze loan status and repayment performance
- Identify monthly loan application trends
- Analyze loan applications by state
- Understand borrower characteristics
- Analyze loan terms and purposes
- Calculate key financial KPIs
- Present insights through interactive visualizations

---

## 📊 Dashboard Pages

### 1. Summary Dashboard

The Summary page provides a high-level overview of the bank's loan portfolio.

### Key KPIs:
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Good Loan Applications
- Bad Loan Applications

### Key Analysis:
- Good Loan vs. Bad Loan
- Loan Status Analysis
- Funded Amount vs. Amount Received
- Overall Loan Portfolio Performance

---

### 2. Overview Dashboard

The Overview page provides deeper insights into loan applications and borrower patterns.

### Key Analysis:
- Monthly Loan Application Trends
- Loan Applications by State
- Loan Applications by Loan Term
- Loan Applications by Home Ownership
- Loan Applications by Loan Purpose

This page helps identify trends and understand the distribution of loan applications across different customer and loan categories.

## 🔄 Data Analysis Process

The project followed these major steps:

1. **Data Collection**
   - Imported the bank loan dataset into Power BI.

2. **Data Cleaning**
   - Checked data quality and handled inconsistencies.

3. **Data Transformation**
   - Used Power Query to prepare and transform the dataset.

4. **Data Modeling**
   - Structured the data for effective analysis and visualization.

5. **DAX Calculations**
   - Created calculated measures for important KPIs and analysis.

6. **Dashboard Development**
   - Designed interactive visuals and KPI cards.

7. **Insight Generation**
   - Analyzed trends, patterns, and relationships within the loan data.
